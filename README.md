# StayHub - Hotel Booking Platform

## Overview

StayHub is a hotel booking platform built using Spring Boot and PostgreSQL. The project is being developed to explore real-world backend concepts such as authentication, inventory management, hotel search, and booking workflows.

## Tech Stack

* Java
* Spring Boot
* Spring Security
* JWT Authentication
* PostgreSQL
* JPA / Hibernate
* Maven

## Current Features

* User Signup
* User Login
* Password Encryption using BCrypt
* JWT Authentication
* Stateless Security Configuration

## Planned Features

* Hotel Management
* Room Management
* Inventory Management
* Booking System
* Search and Filtering
* Dynamic Pricing
* AI-Powered Hotel Recommendations
* Natural Language Hotel Search
